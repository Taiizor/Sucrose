## Resolution

root_cause: CEF focused and activated its own widget while the wallpaper browser was made, through two independent paths: (1) CefBrowserPlatformDelegateNativeWin::CreateHostWindow shows Chromium's widget with Widget::Show, which without WS_EX_NOACTIVATE in the window info uses SW_SHOWNORMAL, calls HWNDMessageHandler::Activate (SetForegroundWindow) and SetInitialFocus (SetFocus); (2) LoadMainFrameURL asks OnSetFocus(FOCUS_SOURCE_NAVIGATION) and, with no focus handler to cancel it, calls ::SetFocus on the widget (also at every CefHost::navigate). The surface is a child of the shell's Progman and shares explorer's desktop input state, so each call took the desktop's keyboard focus and activated Progman; when the new renderer was allowed to set the foreground (started while its launcher was in front, or the foreground lock had expired) the user's window lost the foreground and their keys went to the wallpaper. The Rust port had dropped the two defaults the legacy CefSharp.Wpf.HwndHost control brought (its FocusHandler cancels FocusSourceNavigation; WS_EX_NOACTIVATE at creation, ActivateBrowserOnCreation off)
fix: commit d860631f; crates/sucrose-engine-cef/src/browser.rs: wallpaper_window_info adds WS_EX_NOACTIVATE to the window info (CEF shows the widget without activating or focusing it and removes the style from the widget afterwards; the CefBrowserWindow keeps it); a focus handler PageFocus answers OnSetFocus with set_focus_answer (FocusRequest::Navigation cancelled for the wallpaper browser, System and popups keep CEF's default) and logs each request and OnGotFocus at debug; docs/FEATURES.md (Web row: D12 note; forwarding row: the parenthetical about CEF taking the focus at page load), docs/ARCHITECTURE.md (renderer row: engines must never activate or take the focus on their own)
oracle_type: specified (starting a wallpaper never changes the foreground or the keyboard focus of the user's window, the legacy and WebView2 behavior) for the probe; derived (the legacy CefSharp defaults and CEF's documented OnSetFocus contract) for the unit tests
