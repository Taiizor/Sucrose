## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **one Sucrose at a time, talking to its renderer** — a second start exits cleanly, and the service and its `sucrose --render` process talk over the D-009 local socket that every later phase builds on.

<objective>
Create `sucrose-ipc` (framing, protocol, endpoint with single instance) and turn `apps/sucrose` into the D-008 service/renderer binary: the service owns the endpoint, spawns one renderer, and the renderer says Hello. Harden the channel (frame limits, garbage, pid check) and restrict the named pipe to the current user.

Purpose: D-21 pulls the IPC core into M1 so the wallpaper path (plan 05) and every later control message use the final channel; D-23 makes single instance work through the same endpoint.
Output: `crates/sucrose-ipc`, `Platform::user_key`, `apps/sucrose/src/{service.rs, render.rs}`.
</objective>
