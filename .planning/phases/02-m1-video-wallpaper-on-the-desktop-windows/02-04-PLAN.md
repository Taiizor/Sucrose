## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **every M1 setting from the C# install, with legacy semantics** — the service start reads the whole D-09 key set from the real files and logs the values it will use, and fixture tests built from the maintainer's real files prove the legacy defaults, clamps and parsing quirks.

<objective>
Extend the plan 03 reader to the full D-09 key set: domain enums in `sucrose-core`, typed defaulting getters, `LegacySettings::load` wired into the service start, then fixture tests for defaults, clamps, BOM, CRLF and sharing violations.

Purpose: FMT-08 (legacy settings read-only, with legacy semantics); the engine options (plan 11), the tray gate (plan 09) and the fullscreen rule (plan 13) read these values; FMT-01 (Phase 3) reuses the reader.
Output: `sucrose_core::settings`, `sucrose_config::legacy::{getters, LegacySettings}`, `crates/sucrose-config/tests/legacy.rs` with fixtures, a "legacy settings" service log line.
</objective>

## Executor environment (applies to every task)

- Run every command from the repository root in WSL. `cargo` is the Windows toolchain behind a wrapper and builds Windows binaries; never install a Linux Rust toolchain. Bun is the only JS runtime; no node/npm/npx.
- `src/` (C#) is read-only reference: never edit or build it. Copying a file out of it is allowed where a task says so.
- The maintainer's real `%APPDATA%\Sucrose` (Setting, Library, Cache) is read-only. Read it, never write, rename or delete anything in it.
- When you start `sucrose.exe`: close nothing of the C# app yourself (D-07); set `SUCROSE_DATA_DIR="$(wslpath -w target/scratch-data)"` and `WSLENV=SUCROSE_DATA_DIR`; never synthesize mouse or keyboard input; stop what you started with `taskkill.exe /IM sucrose.exe /F` (this matches only the Rust binary, never `Sucrose.*.exe` C# processes); stop the app before rebuilding (Windows locks running executables).
- Preserve each file's line endings (`.planning/` and `docs/` files are LF in the working tree; check before editing).
- Before finishing each task: `cargo fmt --all`, and the task's verify command. Before finishing the plan: `cargo xtask ci`.
