## Phase Goal

ROADMAP goal: *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice (UAT gap G-02-6, first half): **the measurement tool can no longer compare two different GPUs, and the C# side is measured again under controlled conditions.**

<objective>
Teach `cargo xtask measure` which GPU each process used and make `--row` refuse a cross-adapter comparison; then measure the C# MpvPlayer on the RTX 3050 with the 02-15 theme on one monitor.

Purpose: the recorded 93.7 % (Rust) vs 16.5 % (C#) compared the Intel UHD with the RTX 3050; measure.rs parsed each counter's LUID and threw it away, so nothing flagged it. Root cause: `.planning/debug/renderer-gpu-load-vs-csharp.md`. Plans 02-17 and 02-18 put sucrose.exe on the same GPU; plan 02-22 measures the Rust side and records the rows.
Output: measure.rs changes with tests, `target/measure/csharp-same-gpu.json`.

Order: this plan runs after 02-20 on purpose, so the Rust measurement in 02-22 uses the final renderer build and the maintainer switches the C# theme only once, after all code changes.
</objective>
