## Phase Goal

ROADMAP goal: *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice (UAT gap G-02-2c, second half): **every monitor shows the same frame, also after a disturbance.**

<objective>
Replace the follower's fixed 1/30 s band and fixed 2 % nudge with a controller that converges: a band of one real frame, proportional speed correction with release near zero, and an integral trim for rate differences; log a periodic drift summary so the residual is visible.

Purpose: in UAT a several-frame offset stayed for more than 30 s after a plug without any seek being logged; a simulation of the current controller (debug session) settles 1.2 to 2 frames off and never re-centres, and with the master below real time a 0.3 s offset drains in about a minute. Root cause: `.planning/debug/monitor-plug-restarts-playback-and-frame-offset.md`.
Output: new controller in `sync.rs` with simulation tests, renderer wiring, FEATURES numbers.
</objective>
