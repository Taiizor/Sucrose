## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **the user can stop Sucrose from the tray and sees why nothing plays** — the tray icon's Quit (success criterion 5) and the D-13/D-20 reasons in its tooltip.

<objective>
Give the service a real Win32 event loop with a hidden top-level window, add the tray icon with Quit through `sucrose-platform`, run an orderly shutdown, and surface every "no wallpaper" reason in the log and the tooltip; honor AppVisible.

Purpose: TRAY-01 and the user-visible half of D-13, D-14, D-15 and D-20.
Output: `EventLoop`/`Tray` in sucrose-platform, `ToService::Failed`, service shutdown and status handling.
</objective>

2. `os_windows/event_loop.rs`: move `EventLoop` here and give it a hidden top-level window of class `SucroseServiceWindow` (`WS_POPUP`, never shown, `WS_EX_TOOLWINDOW`; not an HWND_MESSAGE window, because TaskbarCreated and WM_DISPLAYCHANGE are only broadcast to top-level windows). `LoopProxy` (Send + Clone) posts `WM_APP` to that window for `wake()` and a distinct WM_APP+1 for `quit()`; `run(handler)` dispatches `LoopEvent::Wake`/`Quit` and stops when the handler returns `Flow::Exit`. 3. `icon.rs` (portable, pure): `pick_ico_entry` parses the ICONDIR header (reserved 0, type 1, count) and 16-byte entries (width/height 0 = 256, image size, offset) and returns the bytes of the entry closest to `wanted_px` with the highest bit depth, or None on malformed input (bounds-checked; unit tests with a hand-built two-entry ICO and truncated input).
4. `os_windows/tray.rs`: `Tray::new`: pick the entry for `GetSystemMetricsForDpi(SM_CXSMICON, dpi)`, create an HICON with `CreateIconFromResourceEx(bytes, TRUE, 0x00030000, cx, cy, LR_DEFAULTCOLOR)`, wrap it with `tray_icon::Icon::from_handle`, build a `muda::Menu` with one `MenuItem` "Quit", set `MenuEvent::set_event_handler` to call `proxy.quit()` when that item's id fires, and build the `TrayIcon` with the tooltip. `set_tooltip` truncates to 127 UTF-16 units at a char boundary (NOTIFYICONDATAW szTip limit). Each unsafe call here (GetSystemMetricsForDpi, CreateIconFromResourceEx, DestroyIcon on the owned HICON) gets a `// SAFETY:` comment (D-011).
5. Copy `src/Shared/Sucrose.Shared.Launcher/Assets/TrayIcon.ico` byte for byte to `apps/sucrose/assets/TrayIcon.ico` (copying out of src/ is allowed; never edit src/).
6. `service.rs`: the main thread creates the EventLoop and the tray (tooltip `APP_LONG_NAME`), all IPC reader and child-wait threads send their events over a `crossbeam_channel` and call `proxy.wake()`; the handler drains the channel on Wake. On Quit: send `ToRenderer::Close` to every renderer, wait up to 2 s per child (`try_wait` loop on a worker thread), kill the ones still alive, drop the tray, return `Flow::Exit`; `main` returns Ok. Put the shutdown sequencing in a pure function over a small trait (`RendererControl`) so a unit test can check the order (Close sent to all, then waits, then kills only the survivors). Log "tray icon ready" when the tray exists.
