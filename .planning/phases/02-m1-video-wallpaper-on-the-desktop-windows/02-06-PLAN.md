## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **only a theme Sucrose can play is started, and Sucrose knows its own version** — the full `SucroseInfo.json` contract (FMT-02), the D-13 gate with a distinct reason for every failure, and the date-based version (D-12) that makes the AppVersion check work.

Purpose: FMT-02 and the TYPE-01 gate; with the M0 version 0.1.0 every theme would be rejected, so the version must land before the AppVersion rule.
Output: `sucrose_core::{version, theme}`, fixtures, D-029, the gate in the service.
</objective>
