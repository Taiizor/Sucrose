## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **the selected video plays behind the icons on the primary monitor** — the full path from the legacy selection through the service, the IPC Assign, the renderer's desktop surface and libmpv, on the real Windows 11 26300 desktop. This is the riskiest part of the phase (RESEARCH Summary, Pitfall 1), so it is proven before any expansion that depends on it.

<objective>
Wire the first wallpaper end to end: service gate (Video type, safe relative Source) → spawn one renderer for the primary monitor → `ToRenderer::Assign` → renderer makes itself Per-Monitor-V2 aware, attaches a surface behind the icons (24H2 raised-desktop aware), loads the bundled libmpv (D-18) and plays the file embedded via `wid`, looping. Then turn the attach logic into a pure, fixture-tested classifier with rect math tests.

Purpose: DESK-01 and ENG-01 playback; everything later (tray, settings, monitors, sync, fullscreen) builds on this slice.
Output: `sucrose-platform` surface, monitors and layout, `sucrose-engine-mpv` player, renderer and service wiring.
</objective>
