## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 2` can convert it): *An existing user's selected video theme plays behind the desktop icons on every monitor on Windows through libmpv, survives shell and monitor changes, and pauses for fullscreen apps.*

This plan's slice: **the selected video plays behind the icons on the primary monitor** — the renderer loads the bundled libmpv and plays the file on the plan 06 surface, so the full path from the legacy selection to a visible video wallpaper runs through the final process architecture.

<objective>
Complete the first wallpaper: the renderer loads the bundled libmpv (D-18) only in its own process, embeds an mpv player into the plan 06 surface via `wid` and plays the selected file looping, with mpv hardened against theme-supplied scripts and URLs. Then pin the hardening and the D-20 failure path with tests and check sharpness at a non-100 % scale.

Purpose: ENG-01 playback and DESK-01 with real video; tray, settings, monitors, sync and fullscreen build on this player.
Output: `sucrose-engine-mpv` player, renderer playback wiring.
</objective>

- Before finishing each task: `cargo fmt --all`, and the task's verify command. Before finishing the plan: `cargo xtask ci`.
