# Phase 03 — UI Design Contract

> Visual and interaction contract for the Portal built in Phase 3 (`apps/sucrose-portal`, GPUI via `gpui-kit`, D-004). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Sources: `03-CONTEXT.md` (D-01 … D-26 are locked and not re-asked), `docs/legacy/portal.md` (legacy layout, strings, ranges), `docs/GPUI.md`, `.claude/rules/ui.md`, `exp/GPUI/Sucrose.Portal` (read for what already worked in GPUI; not a base). Values marked "default" are researcher choices that no upstream artifact fixed; the executor may tune them only against a measurement or a screenshot, and must record the change here.

This is a native Rust UI: there is no CSS, Tailwind, shadcn or web view. "px" means GPUI logical pixels. Every user-visible string goes through rust-i18n with legacy key names (D-20); Phase 3 ships English only.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, pill padding, gap between a row title and its description |
| sm | 8px | Gap between header icon buttons, gap between settings rows, dialog button gap |
| md | 16px | Page padding, header and status-bar horizontal padding, settings row padding, dialog content gap |
| lg | 24px | Dialog padding, gap between settings groups |
| xl | 32px | Title bar height, icon-button hit area, empty-state gap |
| 2xl | 48px | Header row height, pagination bar height |
| 3xl | 64px | Empty-state vertical offset from the top of the content area |

Exceptions:
- Card gap equals the user setting `AdaptiveMargin` (5–25 px, legacy default 5). It is the only spacing that may be a non-multiple of 4, because migration must keep the user's value.
- Library card height 160 px and card width 260–400 px (legacy parity, `portal.md` §2). Search box 320 px. Dialog width 480 px (About: 560 px). Settings content column max width 960 px. Status bar height 32 px. Minimum window 900 × 600 px (legacy parity; also the default size).
- Hairlines: borders 1 px, focus ring 2 px, nav indicator 3 px. These are strokes, not spacing.
- Icon-only buttons are 32 × 32 px hit areas (desktop pointer UI; no 44 px touch exception).
- Corner radius: 8 px (cards, settings rows, inputs), 12 px (dialogs, `radius_lg`), full (pills).

## Typography

Exactly four sizes and two weights (regular 400, semibold 600), set through the Sucrose `ThemeConfig`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (semibold 600 for settings row titles and tab labels) | 1.5 |
| Label | 12px | 400 | 1.5 |
| Heading | 16px | 600 | 1.2 |
| Display | 24px | 600 | 1.2 |

Role assignment (the executor must not add other sizes):
- Body 14: search text, tab labels, settings row titles, control values, dialog body, link-card titles.
- Label 12: status bar, card description, settings row descriptions, tooltips, pills, hints, toast detail.
- Heading 16: card title, settings group headings, dialog titles, link-card group titles.
- Display 24: empty-state and search-empty titles, About product name.
- Card title and description sit on an image overlay: white text, white at 82% opacity for the description (the only hard-coded colors allowed, `ui.md`).
- Single-line text truncates with an ellipsis; nothing in this phase wraps except dialog bodies, descriptions in settings rows, empty-state bodies, banner text and toast text.

## Color

Tokens come from the Sucrose `ThemeConfig`. The split is a target for visible surface area, not a pixel audit.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Dark `#202020`, light `#F3F3F3` | Window and page background. Opaque when backdrop is None and no background image is set; alpha 0.78 when a backdrop or a background image is active so it shows through (prototype default `DEFAULT_TINT`) |
| Secondary (30%) | Dark `#2B2B2B`, light `#FFFFFF` | Settings rows (alpha 0.55 over the page), header row, status bar (alpha 0.5 of the active tint), dialogs (opaque), card border track. Borders: dark `#3A3A3A`, light `#E0E0E0` |
| Accent (10%) | Dark `#60CDFF`, light `#005FB8` (primary foreground: black on dark, white on light) | See the reserved list below |
| Destructive | Dark `#FF99A4`, light `#C42B1C` | See the reserved list below |
| Muted text | Dark `#B0B0B0`, light `#5F5F5F` | Descriptions, status bar, placeholders. Must keep 4.5:1 against its surface at full opacity; if a backdrop lowers it, the surface alpha floor is 0.78 |

Accent reserved for:
1. The 3 px indicator and selected state of the active tab (Library, and the active settings page).
2. The "Selected" pill on the card of the theme that is selected and running.
3. The 2 px card hover ring (accent at 55% opacity) and the keyboard focus ring on every focusable element.
4. The filled primary button in dialogs and settings (Close, Jump, Select a background image). The Move Library confirmation is destructive instead, see below.
5. Switch and checkbox "on" state, slider fill, and the active page button in pagination.
6. The Use-in-flight spinner on a card.

Accent is never used for body text, icon buttons at rest, links inside dialogs (those use foreground with underline), or card titles.

Destructive reserved for:
1. The confirm button of "Change Library Location" when "Move your current library" is on (the old folder is removed).
2. The red incompatible-theme badge on a card ("Update Sucrose to use this theme", D-18). This is the one non-action use; it is kept red for legacy parity and is an unavailable-state signal.
3. Error text in toasts and banners that report a failure (icon and heading only; body stays foreground).

Backdrop and background image rules (D-21, D-22, UI-01):
- Backdrop select values: None, Mica, Acrylic, Tabbed. Mapping to GPUI: Opaque, MicaBackdrop, Blurred, MicaAltBackdrop. A stored value the OS cannot show is applied as None; the setting is not rewritten.
- The background image is a full-window layer below all content, fit by `BackgroundStretch` (None, Fill, Uniform, Uniform to Fill = none, fill, contain, cover), layer opacity `BackgroundOpacity / 100`. Decode on a background thread at no more than the window size times the scale factor; drop the previous image from the GPUI atlas when it changes. An animated GIF animates only while the window is visible and not minimized.
- Light, dark and System are one setting; the backdrop is a separate setting (D-21). The accent colors above apply to both backdrops.

## Layout Contract

**Window.** 900 × 600 minimum and default, centered, `TitleBar` 32 px (16 px logo, "Sucrose Wallpaper Engine" in Label size). Vertical stack: title bar, header row (48), optional connection banner, content (flex, scrolls), pagination bar (48, library only), status bar (32). Background layers bottom to top: window backdrop, background image, tinted page background.

**Library mode header row** (left to right): Library tab (icon Library + label), flexible gap, search box (320 px, shrinks to 200 px before anything else collapses), Light/Dark toggle, Premium (Lucide `Crown`), ⋮ (Lucide `EllipsisVertical`; menu: Help, About), a 1 px divider, Settings gear. Icon buttons are ghost, 32 × 32, tooltip on hover (legacy tips). No Store tab, Create Wallpaper, Wallpaper Cycling or Display Preferences, and no disabled placeholders (D-15).

**Settings mode header row** (gear pressed): Back arrow (tooltip Go Back), General tab, Personal tab. The search box and action buttons are hidden. Back returns to the Library with its page, scroll position and search text intact.

**Library grid.**
- Content padding 16. Columns = max(1, floor((W + gap) / (260 + gap))), clamped to `AdaptiveLayout` when it is above 0. Card width = (W − gap × (columns − 1)) / columns, capped at 400; if the cap is reached the row is centered. Card height 160. Gap = `AdaptiveMargin`.
- At the 900 px minimum with the default gap the grid shows 3 columns.
- Page size = `LibraryPagination` (1–100, default 30). The pagination bar is hidden when there is one page or fewer.

**Card** (160 px high, 8 px radius, 1 px border, overflow clipped):
- Thumbnail fills the card (cover fit), decoded at card size on a background thread.
- Bottom strip 56 px with a black gradient (30% to 75% opacity): title (Heading, white, one line) over description (Label, white 82%, one line). Hidden while a hover preview plays and `LibraryPreviewHide` is on.
- Top-left pill "Selected" (accent, check icon) when this theme is selected and running. Top-right red pill with Lucide `PackageX` (tooltip: Update Sucrose to use this theme) when `AppVersion` is newer than the app.
- Hover: 2 px accent ring (55%), hand cursor only when Use is possible; default arrow when Use is disabled. With `LibraryPreview` on, the Preview GIF starts after a 200 ms dwell (default) and stops when the pointer leaves.
- No "…" button and no context menu (D-18). Title, description and the pills must never overlap: pills sit above the strip, the strip never grows.
- Localized title: current language, then Default, then the folder name. A missing description leaves the title alone in the strip.

**Pagination bar** (48 px, centered): Previous, up to 9 page buttons with the legacy ellipsis scheme when pages > 6, Next, a numeric input and a Jump button. Changing page scrolls the grid to the top. The Previous and Next buttons disable at the ends.

**Settings pages.** One scroll column, max width 960, centered, padding 16. Group heading (Heading) then expander rows with 8 gap, 24 between groups. A row: 16 padding, 8 radius, secondary surface at alpha 0.55; left title (Body semibold) over description (Label muted); right control (fixed-width, 200 px for selects and 220 px for sliders); expandable footer separated by a 1 px border for sub-options. Settings apply immediately; there is no Save button and no success toast. A control always shows the value broadcast by the service.

**Settings content in Phase 3** (D-16; keys in their legacy places, Phase 5 fills the rest):
- General: group "Appearance & Behavior": Application Theme (Light, Dark, System; new row, D-21), Startup at Application Launch (None, Normal, Priority, Scheduler), Notification Area Icon (Visible, Invisible) with the footer checkbox "Close all Sucrose applications when the system tray is closed", Window Backdrop (None, Mica, Acrylic, Tabbed) with footer: background image (Select a background image button, Remove button, path text), Background Stretch select, Background Opacity (%) 0–100. Group "Library": Library Location (path text, folder-picker button, open-folder icon button) with footer checkbox "Move your current library to the new location".
- Personal: group "Library": Corrupt Themes (switch plus hint). Group "Appearance": Theme Preview with Library Preview switch and footer switch "Hide Details" (disabled while the preview switch is off), Adaptive Layout (Spacing Distance 5–25, Layout Order 0–100), Library Sorting (Sort Mode: Name, Creation, Modification; Sort Type: Ascending [A-Z], Descending [Z-A]), Library Pagination (1–100). Store-only keys, Deletion Confirmation, Sound, Language and the other pages do not appear (D-16, D-20).
- Numeric fields clamp to their range on commit and show the clamped value; an empty field reverts to the previous value.

**Status bar** (32 px, left to right, Label muted, 16 gap between groups): apps icon, "Pre-Release", framework ("Rust"), architecture (x64, arm64), "v{version}", memory ("{n} MB", total of all Sucrose processes; tooltip lists Service, each Renderer, Portal and the total; "—" until the first report or when the service is unreachable), then a flexible quote (random `Portal.Quoting0..85`, one line, truncated, tooltip is the full text, click copies) and the copyright. Below 1000 px width the copyright is hidden first, then the quote.

**Dialogs** (modal, 12 px radius, 24 padding, 16 gap, 480 px wide, About 560): focus moves to the first action on open and returns to the trigger on close; Escape closes except the tray hint during its countdown. Help: five link rows (Web Page, Documentation, Source Code, Discussions, Report Issue; icon, title, description; open in the OS browser). About: author blurb, product name "Sucrose Wallpaper Engine" (Display size), "Version: v{version}", Release Notes link, Contributors link, Terms of Service, Privacy Policy, Code of Conduct links. There is no "Last Checked" line until the updater exists (Phase 5). Tray hint: static tray-icon illustration (no GIF, memory), message, Close button with a 5-second countdown; shown on the first window close only while `HintTrayIcon` is on and the tray icon is visible.

**Toasts.** Bottom right, 16 px above the status bar, maximum 3 stacked (a 4th closes the oldest immediately), 5 s auto-dismiss (errors 8 s, with a close button); text wraps. **Banners** sit between the header row and the content, full width, 8 × 16 padding.

## Interaction Contract

| Interaction | Contract |
|-------------|----------|
| Use (card click) | Immediate spinner on that card; the request goes to the service (D-11). The "Selected" pill moves only when the service broadcasts the new selection, never optimistically. Repeated clicks: last wins. Failure: toast "Use failed" and the old selection stays. Use is a no-op on disabled cards. |
| Use disabled reasons (priority) | 1 service not connected, 2 newer theme (red badge), 3 non-Video theme, 4 selected and running, 5 fullscreen rule paused or closed (D-23; recovers by itself). Disabled cards stay focusable and expose the reason as their tooltip and accessible description. |
| Search | MaxLength 20, 500 ms debounce, lowercased, filters the whole library (all pages), resets to page 1, Escape clears while focused, Ctrl+F focuses it. Clear (x) button inside the field. No telemetry (D-15). |
| Theme toggle | Click sets Light or Dark explicitly and shows the opposite icon (Sun while dark, Moon while light) with the legacy tooltip naming the target. In System mode the icon reflects the effective theme and a click sets the opposite explicitly. |
| System theme | Follows live OS theme changes through the platform event, with no polling. |
| Settings navigation | Gear enters settings mode on General; Back (and Escape when nothing is focused in a field) returns. Command-line `GeneralSetting` and `SystemSetting` open General (D-16, UI-03). |
| Library location | Folder picker, then validation (empty destination, access), then the confirmation dialog when Move is on, then a blocking progress state ("Please wait while the location is being changed") that disables the library and settings controls for that row, then the wallpaper restarts and the library reloads. A failure restores the previous location and shows the toast above. |
| Startup select | Normal creates the Sucrose-owned entry through the service and is the only working option; Priority and Scheduler are disabled (D-08). Choosing None removes only Sucrose's own entry. |
| Backdrop controls | Disabled options stay visible with their tooltip; the stretch and opacity controls apply live and work on every OS (D-22). |
| Hover preview | Decode at card size on a background thread, only the hovered card animates, frames are released and dropped from the GPUI image atlas when hover ends (D-24). Fast pointer sweeps start no decode (dwell 200 ms). |
| Window close | First close with `HintTrayIcon` on shows the tray hint (then closes); otherwise the Portal closes and the service stays or exits by D-13. A second Portal launch focuses and restores the existing window. |
| Keyboard | Tab order: tabs, search, header buttons, cards (row-major), pagination. Enter and Space on a card = Use. Arrow keys move focus between cards. Every icon-only control has an accessible label equal to its tooltip. Focus ring: 2 px accent. |
| Motion | Hover ring and toast entrance 100–150 ms; no page-transition animation; dialog entrance per component default. Respect an OS reduced-motion capability when the platform layer reports it. |
| Text direction | Use logical start/end ordering (flex row order) rather than left/right geometry, except the image overlay gradient, so RTL can flip when UI-06 lands (Arabic and Hebrew). |

Cache contract (UI-07, default pending the D-25 numbers): thumbnails decode at 360 px wide when the scale factor is at most 1.0 and 720 px otherwise (two buckets so a resize never re-decodes).
