## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 3` can convert it, this plan does not invent one): *The service and the Portal work as one app: the user picks a theme in the Portal's library, "Use" applies it through the service, settings migrate from the C# install and persist, and Sucrose can start with the OS.*

This gap-closure plan's slice: **Sucrose can start with the OS** (SC4, TRAY-03) and turning it off never leaves the setting and the registry disagreeing (review WR-05).

<objective>
Fix WR-05: `disable_autostart` deletes the Run value first and then fails if deleting the Task Manager flag fails, and `set_startup` treats any error as "nothing changed", so the Run value is gone while `General.RunStartup` still says 1. Make the flag removal best effort (as on enable) and let `set_startup` settle the setting by what the OS reports after a failure.

Purpose: TRAY-03 (truth 9 of 03-VERIFICATION, behavior-unverified); review WR-05 ends as fixed.
Output: platform and startup changes with tests.
</objective>
