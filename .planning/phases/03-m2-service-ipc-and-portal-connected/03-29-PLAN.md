## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 3` can convert it, this plan does not invent one): *The service and the Portal work as one app: the user picks a theme in the Portal's library, "Use" applies it through the service, settings migrate from the C# install and persist, and Sucrose can start with the OS.*

This gap-closure plan's slice: **untrusted theme images cannot exhaust the Portal's memory** (03-VERIFICATION gap 3, review CR-01, threats T-03-25 and T-03-40).

<objective>
Close CR-01: a progressive JPEG of 16384 x 16384 passes today's per-side check and makes `jpeg_decoder` allocate about 1.6 GB before scaling (3 slots in parallel). Add one shared pixel-area limit checked right after `into_dimensions` in both `decode_bytes` functions (and for the preview GIF screen), with tests that a 16384 x 16384 header is refused, and merge the two copies of the JPEG fast path.

Purpose: CR-01 / gap 3; UI-07 (thumbnail memory) and UI-01 (background image).
Output: `MAX_PIXELS`, `check_dimensions`, one `decode_jpeg_scaled`, tests.
</objective>
