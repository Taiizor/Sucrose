## Phase Goal

ROADMAP goal (not yet a user story; `/gsd-mvp-phase 4` can convert it, this plan does not invent one): *Every wallpaper type plays on Windows on every engine that supports it, existing web wallpapers work unchanged with the C#-compatible JavaScript API, and display modes, property editing and the performance rules match or improve on the C# app.*

**Planning round:** Round A of the five D-31 planning rounds (04-CONTEXT D-31 "Planning rounds"): D-31 slice 1 only — the engine trait, detection and per-type choice with fallback, CEF bundled through `cargo xtask fetch-engines`, the virtual origin (D-14) and the JavaScript API (PropertyListener, SucroseCompatible.json, the first system data), proven with the maintainer's 8 Web themes and the fixture pages. Rounds B–E are planned after Round A has executed.

This plan's slice: **the D-32 gate, first half** — the pinned CEF dist reaches every build, `sucrose.exe` delay-loads `libcef.dll`, CEF subprocess command lines go to CEF first, and the service and mpv renderers run without CEF. Plan 02 hosts a Web theme in a CEF browser and records the outcome (D-036).

## Settled decisions (reversibility gate)

D-32 (CEF keeps the `cef` crate and delay-loads `libcef.dll`; fallback `sucrose-cef.exe`) is rated costly in 04-CONTEXT and was confirmed by the maintainer on 2026-11-26 as his answer to research open question 1. It gets no new checkpoint:decision. The fallback branch is already decided by D-32, so a failing gate does not stop for a question: Task 2 says what to build instead.

<assumption_delta_decision>

Round A is where the single-engine assumption ends: until Phase 3 every renderer played mpv and the theme gate accepted only Video. "choose the working area or the full display bounds" belongs to Round C (DESK-04) and changes nothing here. Invariant test (adopted): the 04-04 table tests run choose_engine for every wallpaper type against available, missing, not-loadable and unsupported engines, so a later round that re-introduces a single-engine assumption turns them red.
