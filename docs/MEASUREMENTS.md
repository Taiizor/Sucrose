**M1 video wallpaper, reading the numbers.** Same theme, same machine, one monitor, 300 s average after a 60 s warm-up, measured one app at a time (`cargo xtask measure`). RAM and CPU are at or below the C# MpvPlayer engine: the Rust service plus renderer use 618 MB working set against 599 MB for the three C# processes (509 MB for MpvPlayer + Backgroundog), 593 MB private against 1220 MB, and 0.51 % CPU against 0.77 %. The GPU is the exception: the Rust renderer keeps the GPU 3D engine at 93.7 % (peak engine per process, hardware decoding on, VideoDecode about 6 %) while C# MpvPlayer sits at 16.5 %. This is an open performance item for Phase 2 verification or a later phase (mpv `vo`, `gpu-api` and scaling options). "Private (commit)" is the sysinfo `virtual_memory()` value, which on Windows is PROCESS_MEMORY_COUNTERS_EX.PrivateUsage. GPU memory: Dedicated Usage reads 0 on this integrated GPU, so the shared figure is the one that counts.
