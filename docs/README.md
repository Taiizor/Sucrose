# Docs

Documentation for the Rust rewrite of Sucrose (`develop-rust`).

| File | What it is |
|---|---|
| `ROADMAP.md` | Milestones, checklists, measurements. Start here to know what is next. |
| `ARCHITECTURE.md` | Target processes, crates, traits, data flow. |
| `DECISIONS.md` | Decision log (Accepted / Proposed) and open questions. |
| `FEATURES.md` | Parity checklist: every C# feature, per-OS support, status. |
| `PORTING.md` | How to port a feature; NuGet → crate mapping; Skylark types in use. |
| `GPUI.md` | UI framework notes and gotchas. |
| `legacy/` | Detailed behavior of the C# app (reference for porting). |

When the rewrite reaches parity (M7) these files are rewritten to describe the finished project.
